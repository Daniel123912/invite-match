INVITE MATCH — достижения

В комплекте 8 оригинальных SVG-иконок 40×40 px, JSON и CSV с условиями получения, а также PNG-превью.

Для Полины (дизайн):
- Иконки прозрачные, с цветными обводками на полупрозрачной подложке.
- Размер в интерфейсе 40×40, SVG можно увеличивать без потери качества.
- Заблокированная ачивка: opacity: 0.25; filter: grayscale(1). Полученная: opacity: 1.
- Все SVG можно вставить в Figma как векторные изображения.

Для Даниила (backend):
- Файл achievements.json описывает id, название, условие и нужное событие.
- Не выдавайте достижения только на фронтенде: событие/условие проверяется сервером.
- Python Junior/Middle = тест успешно сдан (порог успеха устанавливает ваша система).
- Универсал = успешные тесты в 3 разных направлениях, не 3 повторные попытки.
- Мастер тестов = 5 разных успешно пройденных тестов.
- 7 дней подряд = вход в разные календарные дни без пропусков; нужен учёт посещений.
- Ночная сова = вход с 00:00 до 05:00; нужно определить часовой пояс (например профиль пользователя).
- Профиль готов = заполнены все обязательные поля.

Рекомендуемое MVP: первые 5 и «Профиль готов». «7 дней» и «Ночная сова» потребуют учёта входов. Это дополнительные игровые достижения, не обязательная часть основного функционала.
